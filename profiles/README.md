# Personenprofile

Ein Profil enthält nur Informationen, die für eine sichere und alltagstaugliche
Planung relevant sind. Medizinische Diagnosen und sensible Daten nur eintragen,
wenn sie wirklich benötigt werden.

Neue Profile werden aus `_template.md` erstellt. Bei Minderjährigen gelten die
besonderen Regeln aus `AGENTS.md`.
